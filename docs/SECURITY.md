# Defensive-use policy

AquaVigil is an educational, defensive and read-only demonstration. It must not be connected to a real water utility, SCADA system, PLC, RTU, HMI, dosing system, pump, valve, safety system or public-health reporting endpoint.

The repository contains no scanning, exploitation, credential collection or industrial command functionality. Demonstration incidents are fictional. Report mappings do not establish regulatory compliance.

Before any real-world adaptation, obtain authorization and complete threat modeling, secure authentication/RBAC, encryption, secrets management, malware-safe evidence handling, signed builds, dependency review, logging governance, laboratory validation and qualified safety/engineering review.
